# sample_data

Every name and number in this folder is synthetic.

- SINs were generated by picking 8 digits and computing the 9th so the Luhn
  checksum passes. None of them belong to a real person.
- Card numbers are the public test numbers published by card networks and
  payment processors for development use.

| Folder | What it tests |
| --- | --- |
| `hr/` | A CSV full of SINs in different formats |
| `finance/` | Free text with a Visa and a Mastercard |
| `support/` | One SIN buried in a log line |
| `clean/` | No sensitive data at all |
| `tricky/` | Things that look like SINs or cards but must not be flagged |
